# 🚚 Supply Chain and Transportation Dashboard

## 📌 Project Overview
This project presents an interactive Supply Chain and Transportation Dashboard built using Microsoft Excel. The dashboard provides insights into supply chain operations, transportation efficiency, supplier performance, inventory health, and shipment metrics to support data-driven business decisions.

---

## 🎯 Objectives
- Analyze overall supply chain performance.
- Monitor transportation efficiency.
- Track inventory health.
- Evaluate supplier performance.
- Identify shipment delays and business trends.

---

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Data Cleaning
- KPI Cards

---

## 📊 Key Performance Indicators (KPIs)
- 💰 Total Revenue
- 📦 Total Units Sold
- ⏳ Average Shipping Time
- 🚚 Average Lead Time
- ⚠️ Delayed Shipments (%)

---

## 📈 Dashboard Insights
- Product Type Revenue Analysis
- Inventory Health Status
- Transportation Mode Performance
- Supplier Lead Time Analysis
- Carrier Shipment Volume
- Shipment Delay Monitoring
